  1. 무엇을 물고기 무게를 맞히는 두 가지 방법을 봅니다. 질문을 골라 나누는 나무·숲, 틀린 만큼 숫자를 조금씩 고치는 경사하강법.

  3. 업무에서는 가격 매기기, 입고 계획, 공장 불량 판정처럼 “여러 판단을 모아 하나로 결정”하는 일이 모두 같은 구조입니다.

이 층에 나오는 영어 약어 풀이
  • R² — 결정계수. 평균만 답할 때보다 오차를 몇 % 줄였나 (1 = 완벽)
  • MAE — 평균 절대 오차. 평균적으로 몇 g 빗나가나
  • MSE — 평균 제곱 오차. 손실로 쓰는 값
  • RF — Random Forest, 랜덤포레스트
  • lr — learning rate, 학습률 (걸음 크기)
  • epoch — 에포크. 전체 데이터를 한 바퀴 다 본 횟수

시장 주인이 기록장을 건넵니다. “물고기 159마리를 재 두었는데, 이걸로 무게를 짐작할 수 있겠소?” (이 기록은 실제로 1917년 핀란드 랭겔매베시 호수에서 잡은 물고기를 잰 것으로, 통계 교육용 공개 데이터로 널리 쓰입니다.) 무엇부터 봐야 할까요? 그림부터 그리면 답 없는 보고서가 됩니다. 질문이 먼저입니다.

왜 이 방법을 쓰나

  1. 문제 상황 — 처음 보는 표에서 무엇을 예측할 수 있는지 알고 싶습니다.
  2. 앞 방법의 한계 — 표를 열자마자 아무 차트나 그리면, 차트는 많은데 답하는 문장이 없습니다.
  3. 그래서 이렇게 — 세 질문으로 읽습니다. 얼마나?(길이 몇 cm, 무게 몇 g — 숫자 열) · 어떤 종류?(품종 — 나누는 열) · 무엇이 궁금한가?(오늘은 “무게”). 그다음 마리 수와 이상한 값을 확인합니다.
쉽게 말하면 반 명단을 받으면 몇 명인지, 어느 모둠이 큰지, 이름이 빈 사람은 없는지부터 봅니다.

왜 이 방법을 쓰나

  1. 문제 상황 — 물고기를 몇 개의 비슷한 묶음으로 나눠, 묶음마다 무게를 답하고 싶습니다.
  2. 앞 방법의 한계 — 사람이 정한 질문(“40cm 이상?”)은 감에 의존합니다. 어떤 기준에서 나눠야 가장 깔끔하게 갈리는지 모릅니다.
  3. 그래서 이렇게 — 나무는 모든 특성·모든 기준값을 시험해 보고, 나눈 뒤 묶음 안의 무게가 가장 고르게 되는 질문을 고릅니다. 묶음마다 다시 같은 일을 반복합니다. 질문하는 곳이 노드, 답에 따라 갈라지는 길이 분기, 더 나누지 않는 끝이 잎이고 잎의 값(평균 무게)이 답입니다.

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error

url = "https://raw.githubusercontent.com/adminmrobo/python_machine_learning_lab/main/data/fishmarket_practice.csv"
df = pd.read_csv(url)
df = df[df["Weight"] > 0]
X = pd.concat([df[["Length2", "Height", "Width"]], pd.get_dummies(df["Species"], dtype=int)], axis=1)
y = df["Weight"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)

t3 = DecisionTreeRegressor(max_depth=3, random_state=42).fit(X_train, y_train)
tN = DecisionTreeRegressor(random_state=42).fit(X_train, y_train)
rf = RandomForestRegressor(n_estimators=300, random_state=42).fit(X_train, y_train)

table = pd.DataFrame({
    "학습 R2": [t3.score(X_train, y_train), tN.score(X_train, y_train), rf.score(X_train, y_train)],
    "시험 R2": [t3.score(X_test, y_test), tN.score(X_test, y_test), rf.score(X_test, y_test)],
    "시험 평균 오차(g)": [mean_absolute_error(y_test, t3.predict(X_test)), mean_absolute_error(y_test, tN.predict(X_test)), mean_absolute_error(y_test, rf.predict(X_test))]},
    index=["나무 깊이 3", "나무 제한 없음", "숲 300그루"]).round(3)
print(table)

imp = pd.Series(rf.feature_importances_, index=X.columns).sort_values().tail(5)
imp.plot.barh(color="#1e55c8")
plt.xlabel("importance")
plt.title("Width (thickness) decides most of the forest's answer")
plt.show()

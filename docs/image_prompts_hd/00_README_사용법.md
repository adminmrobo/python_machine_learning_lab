# 이미지 프롬프트 묶음 — 파이썬 머신러닝 연구소 (표지 고화질 + 11층)

## 왜 저화질이었나
기존 지시문의 공통 규칙이 **“native canvas 480x270 pixels upscaled 4x”** 였습니다. 그래서 Genspark가 가로 480점짜리 굵은 픽셀 그림을 그렸고, 1920으로 키워도 점 하나가 4×4로 보였습니다(파일은 1920×1080이지만 실제 정보량은 480×270).
이번 커밋에서는 받은 그림을 픽셀 보존 방식으로 2배 정밀화(960×540)하고 고해상도 화면용 2x 파일을 붙였습니다. 근본 해결은 **처음부터 잘게 그린 그림**이라, 이 묶음의 공통 규칙은 격자를 **960×540(점 하나 = 2×2)** 으로 바꿨습니다.

## 순서 (우선순위)
1. **01_cover_index_HD** — 첫 화면 표지. 가장 먼저. 받으면 이 그림을 나머지 요청의 참고 그림으로 씁니다.
2. **02_cover_11** — 새로 연 11층 표지.
3. **03_ill_11** — 11층 일러스트 2장 (단계 1 뒤, 단계 3 뒤 자리. 지금은 비어 있음).
4. **04_scene_11** — 11층 단계별 장면 5장 (선택).
5. **05_covers_HD_rest** — 나머지 표지 15장 고화질 재생성 (선택, 시간 날 때).

## Genspark에 넣는 법
- 요청마다 맨 앞에 `00_COMMON_RULE_cover.txt`(표지) 또는 `00_COMMON_RULE_3x2.txt`(일러스트·장면)를 붙이고, 그 아래 각 그림의 지시문을 붙입니다.
- 캐릭터 참고 그림: 저장소 `build/sprites/`의 기본 표정(doc_e08 · asst_e13 · fly_e10 · robo_e13 · sia_e13 · moa_e13 · x1_e13 · x2_e13 · x3_e13)을 함께 올립니다.
- 지금 표지(cover_index)를 참고로 올릴 때는 “캐릭터 모양만 참고하고, 픽셀은 더 잘게(2배 촘촘하게)”라고 한 줄 덧붙이세요. 그대로 따라 그리면 다시 굵은 픽셀이 나옵니다.
- **PNG로, 가능한 큰 크기**로 받아 주세요. 크기가 작게 나와도 그대로 주시면 격자를 찾아 정리합니다.
